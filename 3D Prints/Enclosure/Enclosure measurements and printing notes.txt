Exporting the enclosure for printing:
- In Blender's "Scene" panel (bottom right, 5th icon from top) make sure unit scale is 1000.0 
- Hide all "Cutter" parts, they are grouped under the "Cutters" section.
- Select all visible parts of each section in turn and export them separately: MainSection, and Lid.
- Do this by selecting this way:
  - Click once on the middle of the object you wish to export (either the MainSection or the Lid).
    - This click will register the name of the object, so that when you export, that will be part of the file name.
  - Right-Click on that object's section in the hierarchy tree (such as MainSection or Lid) and press "Select Objects".
- In the object list, make sure all MainSection (or Lid) parts are selected, and the Cutter parts are NOT visible or selected.
- Use the features of the "Mesh: 3D Print Toolbox" add-on to export the selected part group as a single STL file (install the add-on first if needed).
- Make sure you have clicked on the selections as instructed above, or else the exporting tool will try to give the two objects the same file name.
- When exporting, make sure the "Apply Scale" checkbox is checked.

Tip: Only export it as two separate files if you are doing this for your own printer. If exporting for a third party service like Shapeways, just export everything as a single file so that you aren't charged for two separate things at Shapeways.

After Printing:
- Drill the screw holes out a tiny bit with your 7/64" drill bit.
